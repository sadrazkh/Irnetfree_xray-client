Features

Everything you expect from a client, and more

From protocols and getting past filtering to household users and routers. The full list is in the guide (Persian).

Protocols and configs

  • VLESS with REALITY, XTLS-Vision and XHTTP; VMess, Trojan, Shadowsocks, Hysteria2, WireGuard, SOCKS and HTTP
  • TUIC and AnyTLS on sing-box
  • MASQUE and WARP: WARP sign-up in the app, and WARP+ with a key
  • Full Xray and sing-box JSON configs
  • Import a link, a subscription, base64, a WireGuard file, Ctrl+V or a QR code

Three cores

  • Official Xray, Xray-PattN and sing-box, chosen per config
  • Pick a core version and update it from inside the app
  • The app writes each config in the form the running core version understands

Getting past filtering

  • Fragment and noise, plus finalMask and cipherSuites with ready-made presets
  • ECH and the ECH outbound, and uTLS fingerprints
  • Certificate pinning on first use, in place of allowInsecure
  • A clean IP in place of a server's address, kept through subscription refreshes

Subscriptions

  • Manual and automatic refresh, with bars for data used and time left
  • Sort by ping, and a "next config" button when a connect fails
  • ⚡ Find the fastest config in each subscription
  • Selection, chains, routing and groups stay in place when a panel rotates addresses

Routing

  • Simple modes: global, bypass Iran, bypass China, direct
  • Rules by domain, IP and geoip/geosite
  • Advanced routing: several profiles, a shared base, a flow tree and share links
  • A config per app on desktop, and app selection on Android

Chains, groups and the pool

  • Chains: traffic passes through several servers in a row
  • Groups: several configs act as one, by load balancing, fastest or fallback
  • Proxy pool: several configs at once, each on its own port
  • Corporate WireGuard: AllowedIPs become a routing rule

Network and users

  • LAN and hotspot sharing, with a link and QR code for each person
  • Users: passwords, daily and monthly data caps, allowed hours and a config each
  • Content filter and speed limits per user
  • Two internets at once: balance, failover or split XHTTP

Stats and diagnostics

  • Live speed, a 60-second chart, usage per config and per route
  • Traffic by site and live connections by app
  • TCP ping, real delay, IP and leak checks

Reliability and protection

  • TUN or proxy: tunnel the whole system, or only the apps that read a proxy
  • Leak guard and kill switch
  • Automatic recovery after a network change or wake from sleep
  • On Android: a stall watchdog, a persistent log and an engine restart

Router: the whole house, nothing to install

  • Every device at home, phones and TVs included, goes through the VPN just by joining the Wi-Fi
  • A web admin page and LuCI integration, a kill switch and remote access
  • A captive portal for users, and traffic by site per device
  • CI runs the package on OpenWrt 23.05 and 24.10

Start in a minute

Four steps to connected

Open the app

The first time, it asks to download the Xray core and the routing files. Press Download.

Paste a config

Copy a config or subscription link and press Ctrl+V anywhere in the app. On Android, use Add config.

Pick one

Choose the config from the menu on the Connect page, or press Auto to find the fastest.

Connect

Press the big button. Green means connected.

IRNetFree is a client and doesn't provide servers, so you need your own config or subscription. You can get Cloudflare WARP from inside the app.

The toolbox: IRNetFree Plus

A separate tools app: a clean-IP scanner for Cloudflare, Fastly, CloudFront and Gcore ranges, plus Server and Configs sections.

FAQ

Answers to what people ask most

Does the app provide servers or free internet?

No. IRNetFree is a client and needs your own config or subscription. The only exception is Cloudflare WARP, which you can get from inside the app.

Why does it download something the first time?

The cores and routing files update separately from the app, so they're downloaded with your permission the first time.

Why does Windows ask for admin rights?

TUN mode creates a virtual network adapter, and the kill switch and LAN sharing change the firewall; on Windows all of these need admin rights. That is why the Windows app asks for them when it opens. Details

My Mac won't open the app.

The app isn't signed with an Apple certificate, so macOS may refuse a plain double-click the first time. The fix is in First run on a Mac.

Is there an iPhone (iOS) version?

Not for now. What works today: join the Wi-Fi of a router that runs IRNetFree, or turn on LAN sharing on desktop or Android and set the proxy in the iPhone's Wi-Fi settings.

Where do my configs and keys go?

They stay on your device and aren't sent anywhere. The app only fetches the subscription links you added, and talks to GitHub for updates. Security

How do I know the file I downloaded is untouched?

Each release has SHA256SUMS-… files next to the downloads. Hash your file and compare it with that file's line. On Windows:

certutil -hashfile IRNetFree-Setup-x.y.z.exe SHA256

On macOS and Linux: shasum -a 256 <file> or sha256sum <file>

Android got stuck. What should I do?

Open Logs → Share and send a report.
