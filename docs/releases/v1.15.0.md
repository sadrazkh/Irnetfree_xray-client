# v1.15.0 — Cancel any time, share the phone's VPN over Wi-Fi, and your server stays selected

A usability release on every platform, asked for by the owner right after v1.14.0.

## Everywhere

- **Cancel while connecting.** A connect that hangs (a dead server, a slow network) can now be stopped. On the
  desktop the power button reads «لغو» / Cancel while connecting, and so do every ▶, the pool's connect button,
  the picker's Auto row and the tray. The router's web UI gets the same. On Android the Home screen and the
  notification offer Cancel. A cancel ends exactly like a disconnect: the core stopped, the guard, kill switch,
  proxy and UDP block given back, and the UI never flips back to Connected from the cancelled attempt. Four real
  gaps the desktop had here were found and closed on the way: a core left running after a cancelled switch, a kill
  switch armed after the disconnect had already lifted it, "Connecting…" stuck after a settings rebuild, and the
  proxy mode's UDP block not given back.
- **The selected server stays selected.** v1.14.0 clears a stale `activeServerId` at launch, and the selection was
  derived from it, so every restart fell back to the first server. The selection (a server, a chain, the pool or
  advanced routing) is now stored on its own and restored on launch; if it was deleted it falls back to the last
  connection, then the first server.
- **Subscriptions fold on the Servers page.** Each subscription is a group you can open and close (remembered),
  with its own refresh and its quota and time left in the head. The Subscriptions page stays for adding and editing.
- **The version** sits small under the logo.

## Android

- **Switching never mixes up the connection.** Rapid taps, reconnect, ⚡ and disconnect-then-connect always end
  with one tunnel on the last target you asked for; a stale connect can no longer finish later and take over, a
  failure never overwrites a newer connect, and the label and notification name what really runs. A live tunnel
  now switches in place (no gap without the VPN), and ⚡ applies nothing if you connected or disconnected while it
  was measuring.
- **LAN sharing.** Settings → LAN sharing opens a SOCKS5 and an HTTP proxy for other devices on the phone's Wi-Fi
  and hotspot while connected (defaults 10810 / 10811), routed exactly like the tunnel, on all three cores. A
  generated username and password are on by default (visible, copyable, changeable; a warning if you turn them
  off), and the phone's addresses are shown as ready-to-copy `socks5://` and `http://` links. If a port is taken,
  the tunnel comes up without LAN sharing and says so.
- **A friendlier phone UI.** A bar pinned at the bottom with the current server and Connect, bigger touch targets,
  pull-to-refresh on Servers, a smooth list for hundreds of servers, and snackbars instead of silent failures.

## Check on your own devices
- Desktop: cancel a connect to a dead server; restart the app and see the same server selected; fold a group,
  restart, still folded.
- Android: cancel while connecting; switch servers quickly; turn on LAN sharing and use the shown `socks5://` link
  from a laptop on the same Wi-Fi (and through the phone's hotspot).
