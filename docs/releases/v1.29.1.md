# v1.29.1 — Android's groups catch up: the dead member set aside, the fallback, real pings for UDP servers

By the version rule: the phone gets what the desktop and the router have had since v1.29.0 — an improvement of what
exists, the third number. The Persian Android interface is still being built and comes as v1.30.0.

## What the owner asked for

«ادامه بده فارسی اندروید و گروه اندروید رو تموم کن», then «تموم شد ادغام کن و نسخه بده» — the group part was done,
the Persian interface not yet; this release carries the group part.

## What it does (Android)

- **A group member that stays dead is set aside by the app** — the same rules as the desktop (core/GroupEvict.kt, a
  port of src/main/groupEvict.js): dead 90 s while another member answers; no streak while the whole group is down;
  tested every 3 min (doubling to 24 min) through a throwaway core; back after two answers 30 s apart; kept across a
  reconnect of the same plan for 30 min.
- **How the phone sees the health check:** only while connected with a group, the core's metrics listen on a free
  loopback port and are read every 30 s; a change rebuilds by connecting the same selection onto the live tunnel —
  the gap-free switch of v1.29.0, no mux test — and waits (saying so) while settings are pending. The phone's
  in-process core has no command line for HandlerService, so the desktop's restart-free removal is not possible here:
  a set-aside drops the open connections once, as a switch does.
- **The group fallback** (`fallback`, a WARP say): dialled as `T~fb`, never probed, taken when no member answers —
  as the desktop builds it. It arrives with a desktop backup or share; the phone's group editor does not offer it yet.
- **Real pings for UDP-only servers** (WireGuard, Hysteria2, MASQUE): the home ping and "ping all" measure them
  through a throwaway core, as ⚡ fastest already did — no more × for a server that works.

## Underneath

- ConfigBuilder: `expandGroups(outbounds, skip)` with the live map and `direct` flags; metrics only with a group.
- XrayTester.coreLock shared with the UI's test lock; the group watch takes it with tryLock, never waits on it.
- GroupEvictTest: 12 tests mirroring tests/groupEvict.test.js, groupLive's evictor part, the fallback cases of
  tests/groups.test.js, the health parsing and the loopback read.

## Not proven here

On the phone: a set-aside rebuild, the metrics read, the UDP pings.
