# v1.13.1 — OpenWrt: installable in one line, back up after a reboot

OpenWrt only. `src/main/` is byte-identical to v1.13.0; the desktop and Android
did not change.

## The installer

`openwrt/install.sh` — one line on the router:

```sh
sh -c "$(wget -q -O - https://raw.githubusercontent.com/sadrazkh/Irnetfree_xray-client/main/openwrt/install.sh)"
```

Refuses anything but OpenWrt 24.x (23.05's feed has node 18; 25/SNAPSHOT use
apk), installs `node kmod-tun nftables unzip ca-bundle`, fetches the newest
release's ipk (or takes a local one: `sh install.sh /tmp/<file>.ipk`), and
prints the URL with the router's token. The QEMU smoke now installs with this
same script, so it is exercised on every push.

## Connect at boot

On a router `autoConnect` defaults to **on** (a stored "off" still wins) and,
because the service starts before the WAN has an address or the clock is set,
a failed boot-time connect retries every 15s for five minutes. A connect made
by hand, or a disconnect, ends the retries. Everywhere else: one attempt, as
before.

## A testable package from every push

The `Tests` workflow keeps `irnetfree_<v>_all.ipk` as the artifact
`IRNetFree-OpenWrt-dev`; tags still publish it to the release.
