# v1.17.0 — Choose your core's version

Asked for by the owner: in Required files, beside each core's Update, a way to pick a version — a few stable releases,
pre-releases on demand, the suggested and the latest marked — and install it, upgrading or downgrading, cleanly.

## Desktop (Windows, macOS, Linux) and the router's web UI

- **Choose version** — Xray, Xray-PattN and sing-box each get a version picker next to Update (geo files, tun2socks and
  wintun keep their single button). Android bundles its cores in the APK and has no download option, so it is unchanged.
- The modal lists the six newest stable releases that have a build for this system (and with one switch the four newest
  pre-releases), each with its age and size and the badges ⭐ Suggested (the version this release of the app is verified
  with: Xray 26.3.27, Xray-PattN 26.9.22, sing-box 1.13.14), Latest, Installed and Pre-release. The suggested and the
  installed version are always listed, even when older. Actions read Upgrade, Downgrade (with a short warning below the
  suggested version) or Reinstall; progress and the result show in the card.
- **Safe by construction** — the chosen release is downloaded, extracted, run once (`version` must name that release),
  and only then put in place by the same atomic replace the Update button uses; any failure leaves the installed core as
  it was, and a version install never replaces the geo files. Not while connected or connecting: disconnect first.
- **One writer per core** — Update, the weekly updater and a version install never run on the same core at once.
- **Honest over a slow link** — if the answer of an install is lost (a proxy or the remote relay ending a long request),
  the picker asks the service how it ended instead of guessing; on Windows a core file held by a running latency test is
  reported in plain words, with nothing replaced.
- **Update is unchanged** — it still installs the latest stable release.

## Check on your own devices
- Windows: open Required files → Choose version for Xray, downgrade one step, reconnect, then upgrade back.
- Router: the same from the web UI; sing-box's ARMv7 build installs and the tunnel comes up.
- Try it while connected: it asks you to disconnect first.
