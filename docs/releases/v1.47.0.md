# v1.47.0 — SNI spoof, per config

By the version rule: a new capability, so the second number goes up.

## What the owner asked

The SNI spoofing of patterniha's tool and V2Box, built in: per config, as configurable as it gets, an extension that can be turned on and off, its files from Settings, and a word to go and download them when they are missing. Not on Android, which needs root.

## How it works

sing-box 1.14.0 and later has it: a forged ClientHello carrying an allowed name goes out before the real one, made so the server drops it (by default a sequence number just left of its window), while a DPI that reads names sees the allowed one. The app writes `tls.spoof` and `tls.spoof_method` into the config of a server that asks for it, which then runs on sing-box. On Windows sing-box carries the WinDivert driver inside itself.

## What changed

- **An extension, SNI spoof**, off by default. Turned on without sing-box 1.14 or later, it says so and opens Required files on sing-box.
- **Per config** (the Security tab): on or off, the allowed name, or several names of which one is picked at random at each connect, and the method: wrong-sequence (default), wrong-checksum, wrong-ack, wrong-md5, wrong-timestamp.
- **Never silently without it:** a config that asks for the spoof runs on sing-box or does not run, with the reason: sing-box missing or older, not elevated, or a transport sing-box cannot carry.
- **Off, every config is the same to the byte.**

## After the review

- A config asking for the spoof inside a chain, a group, a routing or the pool is refused by name: the spoof runs only on a config connected alone. A LAN user whose config asks for it is blocked, never sent without it.
- A spoofing config that carries patterniha masks (noise, final mask, dial mode) is refused: sing-box has none of them.
- A sing-box that does not say its version gets its own message.
- The probe also runs the spoof beside the cut hello (record_fragment).

## Limits

- **A config connected alone.** Not inside a chain, a group, a routing or the pool.
- **Works on Windows, elevated** (the app already relaunches as administrator for TUN). Linux and macOS need root, which the desktop app does not run as, so it is refused there. **The router refuses it in this version:** it runs sing-box configs on Xray.
- **Only configs sing-box can carry:** TLS over TCP, ws, grpc, httpupgrade. Not XHTTP, and Reality is unproven on sing-box.
- It beats DPI that only reads names. In Iran it depends on the ISP; patterniha's users report resets after the handshake on some ISPs and trouble on low-latency fibre.
- The ping of a spoofing config is measured without the spoof.

## Tested

- `tests/sniSpoof.test.js`, engine choice, builder, extension gate, editor table; 15 config shapes pass `sing-box check` on 1.14.4.
- `scripts/probe-sni-spoof.js` (CI, Linux, root, two network namespaces): the forged hello with the allowed name goes out before the real one, left of the window, and the connection still works, for wrong-sequence and wrong-checksum.
- Not run on this Windows machine: it would load a kernel driver.
