# v1.13.2 — OpenWrt 23.05 too

OpenWrt only; no code under `src/` changed.

The owner's router runs OpenWrt 23.05.4, and v1.13.1's installer refused it
("needs 24.10"). 23.05's feed carries node **18.20.6** (24.10's carries 20),
and the runtime uses nothing newer than Node 18 — so the installer now takes
`23.05*` as well as `24.*`, and after `opkg install node` checks that the node
that arrived is 18 or newer instead of assuming.

The QEMU smoke runs on both releases now (`24.10.2` and `23.05.5`, a matrix,
`fail-fast: false`): install with the installer, service up, connect, TUN
device, sing-box's policy route, our nft table, the fw4 zone, a live change
of the exclusion list, a clean teardown — on node 20 and on node 18.

Still not: 22.03 and older (no usable node), 25/SNAPSHOT (apk, not opkg).
