# v1.7.6 — v1.7.5 with the APK

The app is byte-for-byte v1.7.5: the bundled country-flag font, so a country
code renders as a flag on Windows as it already did on macOS (see
[v1.7.5](v1.7.5.md)). This tag exists because v1.7.5's Android job never got
as far as compiling.

`android-actions/setup-android@v3` installs `tools platform-tools` by default,
and Google removed the deprecated `tools` package from the SDK repository on
2026-09-16 (the action's issues #537 and #538, filed the day before and the
same day). Every Android job — in the release workflow and in Tests — failed at
"Set up Android SDK", before a line of this repo was read, so v1.7.5 shipped
with the Windows, macOS and Linux assets and no APK.

Both workflows now name the packages they want (`packages: platform-tools`);
the Gradle build downloads the platform and build-tools it needs by itself. A
test fails if either workflow goes back to the default or ever asks for
`tools` again. The Android job is green on main with this change.

`npm test` 788/788. Nothing in `src/` differs from v1.7.5.
