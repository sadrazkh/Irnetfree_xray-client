# v1.10.0 — Android: the config list is design 2c

Android only. Nothing in `src/` changed (`npm test` 796/796).

## What was wrong with the old list

Every row carried five 24dp icon buttons — test, copy, QR, edit, delete —
beside a name, a protocol chip and a latency chip. On a 380dp phone that is
sixty-five tap targets across thirteen servers, four of them destructive and
all of them about nine millimetres apart, while the row's actual content (the
name, the host) got whatever width was left and truncated to `TCP 12…`.

## The list now

One quiet line per server: the flag, the name, `VLESS · host:port`, and the
ping it last answered with. Tapping a row selects it **and** opens it in place,
which is the card the design draws — the open one is the one marked **IN USE**.
Inside it: three tiles for what was measured, then one row of five labelled
actions with real words instead of icons.

- **The flag comes out of the name.** Nothing in a share link carries a
  country, but panels write a flag into the name (`🇮🇹-CDN1`,
  `TCP 12 🇩🇪-Sadra|📊1.15TB`) — so the list shows it on the left and prints the
  name without it, along with the separator that was holding it on. A config
  with no flag shows its protocol instead. `ServerLabelTest` pins this against
  the owner's own subscription names.
- **`USED` is `UP` instead.** The design's third tile is total bytes for that
  config; this client keeps no per-config byte count, and a tile that can only
  ever say `—` is worth less than the upload figure, which is the side that
  actually goes bad. TCP and REAL are the design's.
- **Delete asks first.** It used to be one of five identical icons; it is now a
  labelled action one tap inside a card, so it confirms.
- **Subscriptions stay in their own sections**, as they are on Windows — what
  you added by hand first, then one section per subscription, each with its
  count.
- The header is the design's: *Servers*, a `ping all` pill that says `testing…`
  while it runs, and a `+` that opens a chooser for link/subscription,
  WireGuard or SOCKS. The search field stays (option 2a keeps one, and
  thirty-one configs need it).

`StatChip` and `ProtoBadge` are gone — the card replaces both.

## What this release cannot claim

No device was in the loop; the layout is transcribed from the design's own
measurements and compiles green with 68 JVM tests. How it feels under a thumb
is a question for the phone.
