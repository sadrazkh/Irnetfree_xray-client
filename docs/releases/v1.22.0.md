# v1.22.0 — The home screen's traffic path, as a flow with a colour per route

## What the owner asked for

"The routing page's picture is beautiful — make a minimal one, just as beautiful, for the top of the home screen."
He approved a sample, and asked for one more thing: each route's own colour, so it is clear where, say, the direct traffic
goes and nothing mixes.

## The home screen (desktop, the router's web UI)

- **The traffic path is now the routing page's flow, minimal:** this device → the rules → ⚓ the base → the targets.
  - The lines are drawn from where the boxes land and move while connected.
  - A narrow window stacks the columns, and each rule says in words where it leads.
- **A colour per target, on every line to it:**
  - direct is green, block is red;
  - each proxy target takes the next of five colours (blue, violet, amber, pink, coral), with darker shades in the
    light theme;
  - a target box is tinted in its colour, and its traffic is written in it;
  - each rule carries a dot of its target's colour.
- **Every shape the old path drew:**
  - **A routing profile:** its first four rule nodes with "+N more", plus the app's own rules (ad blocking, the local
    network, the simple mode's Iran or China), the bases, and "exit at the base".
  - **One server or a chain under a simple mode:**
    - ads → block;
    - the local network → direct;
    - Iran or China → direct;
    - everything else → the config.

    A raw JSON server in proxy mode runs its own routing, so it is drawn alone. Without the geo files, no geo rule is
    drawn: the core has none.
  - **The proxy pool:** one line per local port.
- **Live figures:**
  - the device box shows the session's live speed;
  - each target shows its own counters;
  - the exit IP sits in the corner.

## Unchanged

Every config is byte-identical to v1.21.1: this round only touches the renderer.
