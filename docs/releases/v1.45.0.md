# v1.45.0 — Safer deletes, a cleaner list, and links that open with the app

By the version rule: new capabilities (links that open the app, the next config), so the second number goes up.

## What the owner asked

From a look at the app as a new user meets it, he chose seven of the proposals: «1و2و3و4و5و7و9 رو بساز بره». Left out on his call: a simpler Home in simple mode, and a warning before a subscription runs out.

## What is new

**1. Deleting (desktop, router).** "Delete all" sat beside "Test all" and emptied every server and chain with no question. It now asks, and sits in the toolbar's ⋯ menu. Removing a subscription asks too. Deleting one server takes effect at once and offers Undo for 12 seconds, which puts back the server, its place in each chain, its last test and the selection. Android already asked first.

**2. An empty Home (desktop, router).** With nothing to connect to, Home shows what to do and two buttons, not a ring and empty figures.

**3. Persian text (desktop, router).** `--mono` labels fell through to Cascadia Mono's monospaced Persian, with letter-spacing on top, which broke words apart. Persian now takes the UI font and sits tight, and Latin stays monospaced. Digits are one kind on the app's screens: the strings, counts and dates that used Persian digits now use Latin, as every other number in the app did. A few remain: some full-sentence messages from the core logic, routing-share errors and the printed users' sheet. Android's strings are unchanged.

**4. Sort by ping (all three).** A toggle shows each group fastest first: real delay, then TCP, then untested in their order, then what failed. It is a view and the stored order never moves. On the desktop the list moves when the toggle is turned on and when a whole test ends, and a row's own test leaves it where it is. On Android it moves when no test is left running. A refresh that moves a server to another address or port now drops its old test, which described somewhere else.

**5. Compact rows (desktop, router).** A row went from about 82 px to 57. Test and connect stay in plain sight, and edit, copy, QR and delete moved to a ⋯ menu, so delete is no longer beside connect. The figures read `TCP 88`, `↓ 213`, `↑ 305`, and ⚡ now only means "test".

**7. Links open with the app (desktop, Android).**
- `irnetfree://import/<percent-encoded>` and `irnetfree://import?url=<…>&name=<…>` bring one subscription or one config. `irnetfree://routing/…` opens its existing preview.
- On Android, `vless://` and the other config links open with the app too, and text can be shared to it.
- Any web page can make a browser open such a link. So the app always asks first, showing a subscription's host and not its secret path. Nothing is saved before that, and nothing ever connects.
- The question cannot be dressed up: a look-alike host shows as its `xn--` form, a URL with a backslash is refused, and a name is cut to one line with no bidi controls.

**9. The next config (all three).** When a connect fails on a plain server, a button offers the next one: the same subscription first, then the rest; the fastest measured, then untested in list order, then what failed its test. The round never repeats a config until the user chooses for themselves.

## Limits

- On Windows the app runs as administrator, so opening a link may show a UAC prompt.
- A protocol registration stays in the user's registry after an uninstall.
- Android keeps its Persian digits and its own row layout. Those two items were about the desktop's page.
- Links do not reach the router or the headless server, which have no OS handler to receive them.
- On a panel that shuffles a country's slots between IPv4 and IPv6, the next config can be either kind: its name says which.

## Tested

- `npm test`: tests/deepLink.test.js (every accepted form, what is refused, and that asking comes first), tests/desktopUx.test.js (sort order, moved servers, next config, the button's states, delete and Undo with the real handlers' shape, the menus, the empty Home, Persian labels).
- Android JVM tests in CI: DeepLinkTest with the same cases, NextConfigTest, ServerGroupsTest.
- The real page and the headless server in headless Chrome, with a test panel: empty Home and its buttons, the row and toolbar menus staying inside the window and closing, the sort, delete and Undo reaching the store, the button after a failure, and both languages.
