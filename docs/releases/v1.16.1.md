# v1.16.1 — The router's field round

## Router (OpenWrt)

- **A connection the core refuses says why.** A config the core rejects, or a patterniha `finalmask` server with
  no Xray-PattN, used to be retried every 15-60 s at boot ("Waiting for internet… (attempt n)") and after a drop
  ("Reconnecting… (attempt n)"), with the reason only in the router's log. Now LuCI and the web UI show
  "Error: …" with the reason, and the router tries again every 10 minutes, or at once when you press Connect.
  While it waits, an armed kill switch keeps the LAN blocked, and the log says so. A missing sing-box or core
  file is still retried at the usual pace, since an upgrade puts it back.

## Good to know

- **Feed cores and patterniha servers: install Xray-PattN.** OpenWrt's own xray-core packages (24.12.31, 25.1.30)
  do not know patterniha's `finalmask`, so v1.16.0 ran those servers without their mask. From v1.16.1 a
  `finalmask` server runs only on Xray-PattN. Without Xray-PattN the connect is refused, and the router stays
  disconnected (with the kill switch on, the LAN stays blocked). Install Xray-PattN under Settings → Required files
  in the web UI before you upgrade.
