# v1.24.1 — Newer cores: Xray 26.10.10, Xray-PattN 26.10.13

## What the owner asked for

Look at what the new Xray cores bring. Two things were worth taking now, before any new feature: fixes for bugs the app's
current cores have, and the fix for the WireGuard bug the real-peer probe found in Xray-PattN 26.9.22.

## What changes

- **The suggested Xray is 26.10.10** (was 26.9.30). It fixes:
  - a gRPC outbound that never redialled after a lost connection ("operation was canceled",
    XTLS/Xray-core#6876) — on 26.9.30 a gRPC server stayed dead until the next connect;
  - two Mux client bugs: a race between a new stream and the session closing (#6870), and UDP frames overwritten by
    the next one (#6822). The app muxes per server since v1.24.0;
  - Hysteria's QUIC clients outliving the core that made them (#7100).

  TLS now checks a server's certificate against the core's own root store instead of the operating system's (#7105),
  so a root CA someone injected into the system cannot vouch for a fake certificate. Pinned certificates
  (`pinnedPeerCertSha256`, `verifyPeerCertByName`) work as before.
- **The suggested Xray-PattN is 26.10.13** (was 26.9.22). From XTLS/Xray-core#6771 until #6804, a WireGuard endpoint
  that is an IP went to the core's DNS as a name and came back empty whenever the DNS block names a server
  ("failed to set endpoint …: returning nil for domain …"). The app writes WireGuard endpoints as IPs, so on 26.9.22
  no WireGuard came up at all — the router ran exactly that core. The fork has the fix from 26.9.24.
- **Android** bundles the same two: libv2ray v26.10.10 (Xray-core 26.10.10) and Xray-PattN 26.10.13.

In Settings → Required files the picker now marks the new versions ⭐ and shows an older installed core as older than
the suggested one. «به‌روزرسانی» / Update installs the newer of GitHub's latest stable and the suggested version, as
before.

## How it was verified

- **Every config shape the app writes** goes through `xray run -test` on both suggested cores in CI (the `cores` job,
  `scripts/validate-configs.js`): the plans, DNS modes, TUN, the link forms, the server editor's every field.
- **The real-peer WireGuard probe** (`scripts/probe-wg-base.js`: a WireGuard base, then a chain ending in one, with
  "exit at the base") runs with the suggested Xray as the client and then with the suggested Xray-PattN — the PattN
  run was a warning while 26.9.22 failed it; it now gates.
- The OpenWrt package in QEMU, the Android compile, and the tests on three operating systems.
